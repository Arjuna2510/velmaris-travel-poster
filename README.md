VELMARIS — a travel poster for a place that does not exist. A floating
island-city above a sea of clouds at golden hour, crowned by one great
ringed lighthouse, its waterfalls spilling off the rim into the clouds
below. The program draws the whole poster in code (Python + Pillow, no
network) and writes it to `/output/entry.png`.

![VELMARIS poster](entry.png)

## Run it

```sh
python3 main.py
```

Writes `entry.png` (1024×1024 PNG, under 1 MiB) to `/output/entry.png`
by default; set `MAKEFUN_OUTPUT` to write it elsewhere. The display font
(`fonts/NotoSerifDisplay-Black.ttf`, OFL) is bundled so the poster renders
identically anywhere.
